
# Motorola Sales Analysis Dashboard | Power BI

📊 **Project Overview**

This project presents an interactive sales analysis dashboard for Motorola, built using Microsoft Power BI. It provides insights into sales performance, customer ratings, product quantities, payment methods, and city-wise sales.

### Key Features
- Total Sales and Quantity KPIs
- Monthly Quantity Trend Analysis
- City-wise Sales Distribution Map
- Brand-wise Sales Comparison
- Top 3 Mobile Models by Quantity
- Payment Method Analysis
- Customer Ratings Analysis
- Sales by Day of the Week
- Interactive Month, Brand, and Payment Method Slicers

### Tools & Technologies
- Microsoft Power BI
- DAX
- Data Visualization
- Interactive Dashboards

### Project Objective
To analyze sales data, identify trends, compare brand performance, and present meaningful business insights through an interactive dashboard.
